## 三、技术方案的板块

方案按训练中心「方案设计」阶段的规范组织（需求 → 端边云图、Ontology、BOM/SDK 及契约）：

1. **需求基线与约束** —— 业务目标与验收硬指标、待验证的问题聚焦、不可越过的权限与口径红线、试点前必须补齐的阻断项
2. **最小试点与排除范围**
3. **业务价值及对照测量**
4. **端—边—云架构** —— Mermaid 主图
5. **Ontology** —— 业务对象与关系、ER 图
6. **BOM / SDK 与技术契约** —— 组件清单、接口契约、关键集成点
7. **代理职责与人工控制**
8. **构建计划与责任人**
9. **成功、继续与终止标准**
10. **风险、留存与合规**
11. **附：事实编号索引说明**

方案守住的边界：首期只读试点、不替换现有业务、不回写工单、不自动关单、专业签核不越权；「98%」按**定位准确率**口径使用，不作缺陷归类正确率解释；错误结果不覆盖原始记录。
